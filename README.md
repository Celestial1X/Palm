## โครงสร้างไฟล์

```
palm-system/
├── index.html              ← หน้า Login (เปิดไฟล์นี้ก่อน)
├── css/
│   └── style.css           ← สไตล์ทั้งหมด
├── js/
│   ├── data.js             ← ฐานข้อมูล, Auth, Export Excel
│   ├── login.js            ← Logic หน้า Login
│   ├── station.js          ← Logic หน้าลาน (User)
│   └── admin.js            ← Logic หน้า Admin
└── pages/
    ├── station.html        ← หน้าบันทึกข้อมูลลาน
    └── admin.html          ← หน้าแผงควบคุม Admin
```

---

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. เข้าสู่ระบบด้วย account ที่ต้องการ

## ฟีเจอร์หลัก

### 👑 Admin
- ดูสรุปข้อมูลรวมจากทุกลาน
- อนุมัติ / ปฏิเสธ รายการที่ส่งมาจากลาน
- Export Excel ทั้งหมด / แยกลาน / กรองสถานะ
- ดูสถิติและสรุปยอดเงิน น้ำหนัก ราคาเฉลี่ย

### 🌿 ลานปาล์ม
- บันทึกข้อมูลรับซื้อปาล์ม (เกษตรกร, น้ำหนัก, ราคา, ทะเบียนรถ)
- คำนวณยอดเงินอัตโนมัติ
- ดูประวัติรายการและสถานะ
- Export Excel ข้อมูลของตัวเอง
- ลบรายการที่ยังรอตรวจสอบ

---

## Export Excel

ไฟล์ที่ Export จะอยู่ในรูปแบบ `.csv` (เปิดได้ด้วย Excel)
- ใช้ UTF-8 BOM เพื่อรองรับภาษาไทย
- รองรับ Excel ทุกเวอร์ชัน

> **หมายเหตุ:** ข้อมูลเก็บใน localStorage ของเบราว์เซอร์
> สำหรับ Production ควรเชื่อมต่อ Backend/Database จริง
